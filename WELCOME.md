# 📁 FilesClaw - Welcome

**Your personal file repository for analysis, reports, and documents.**

---

## ✨ Features

### 📄 Markdown Support
- Full markdown rendering with `marked.js`
- Headers, lists, tables, code blocks
- Blockquotes and formatted text
- Perfect for analysis reports

### 🖼️ Image Viewer
- PNG, JPG, GIF, WebP, SVG support
- Full-width responsive display
- Click to view full size

### 📊 File Types Supported

| Type | Extensions | Viewer |
|------|------------|--------|
| **Markdown** | `.md` | Rendered HTML |
| **Images** | `.png`, `.jpg`, `.gif`, `.webp`, `.svg` | Image viewer |
| **PDF** | `.pdf` | Embedded viewer |
| **Text** | `.txt`, `.json`, `.csv` | Code viewer |
| **Code** | `.js`, `.html`, `.css` | Syntax display |

## 🚀 How to Use

### Upload a File

```bash
cd /root/projects/FilesClaw

# Copy your file
cp /path/to/analysis.md .

# Commit and push
git add analysis.md
git commit -m "Add analysis report"
git push
```

### View Your Files

1. **Browse:** `https://krishanbansal000-cmyk.github.io/FilesClaw/`
2. **Click** any file to view
3. **Download** or view raw if needed
